# **Capacitação**

Este é o primeiro documento do **Guia de Capacitação** para novos integrantes do **CloudLabs**. 

A capacitação será realizada utilizando o **cluster Pamonhas**, localizado no **Laboratório 35** (laboratório do professor Hélio).

> ❓ **O que é um cluster?**  
> Um _cluster_ é um conjunto de computadores conectados em uma mesma rede local, trabalhando de forma colaborativa para algo específico.  
> No contexto deste guia, você irá interagir com quatro máquinas: **pamonha1**, **pamonha2**, **pamonha3** e **curau**.

Ao final da capacitação, o aluno deverá estar familiarizado com os principais conceitos de **computação em nuvem**, ter visão crítica sobre os temas e apto a contribuir com o grupo.

---
# **Como o curso irá funcionar**

O guia está organizado em **três módulos**, que devem ser seguidos nesta ordem:

1. **Configuração do hardware**
2. **Configuração dos servidores**
3. **Configuração da cloud**

Cada módulo é dividido em **três partes principais**.

A **primeira** sendo um breve overview sobre o que se tratará ele, bem como material complementar para ajudar e guiar os estudos. Para além disso algumas perguntas serão feitas para o aluno se questionar.

A **segunda** parte será o desenvolvimento das atividades práticas, o cerne da capacitação. As atividades **não são tutoriais passo a passo**, mas sim **guias orientativos** para ajudar o aluno a atingir o objetivo final de cada módulo, aplicando seus próprios conhecimentos e pesquisas.

A **terceira** parte é uma breve seção de encerramento que resume o que foi feito no módulo e o que o aluno deve ter aprendido ou conquistado ao final.

Dessa maneira um módulo deve seguir a seguinte forma:

```markdown
# Objetivo

## Guias de Estudo

## Questionamentos

---
# Atividades

## Atividade 1
...

---
# Conclusão
```
